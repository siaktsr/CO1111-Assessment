Treasure Hunt Adventure

Ahoy, mighty pirates! Welcome to the ultimate Treasure Hunt adventure. Search for hunts created by other players, solve clever riddles, scan QR codes, explore locations, and race against time to claim the highest score.

Every hunt is different. Some require knowledge, some require exploration, and some will test your speed and teamwork. Only the best pirates will reach the treasure first!

Start the Hunt 👇

Treasure Hunt Rules

  1. Each correct answer earns you valuable treasure points.
  2. A wrong answer will deduct points from your score.
  3. Some questions may be skipped, but skipping may cost you points.
  4. The pirate with the highest score wins the game.
  5. If two pirates finish with the same score, the victory goes to the one who finished faster.

How the Hunt Works

  • Browse treasure hunts created by the university team.
  • Find hunts quickly using the built-in smart search, even if you only remember part of the name.
  • Join a game by entering your team name.
  • Solve riddles and answer questions to earn points.
  • Some challenges may require scanning QR codes using the built-in QR code scanner.
  • Certain questions may require visiting real locations, so location permission may be required.
  • Some questions include helpful links that guide you to additional information.
  • If you leave the game accidentally, you can reconnect by entering your team name exactly as before.

About the Project

This application was developed as an examination project by Team C.

The goal of this project is to create a fun and interactive platform where players can enjoy treasure hunts created by other players.

The game includes puzzles, quizzes, QR code challenges, and location-based tasks designed to make every hunt unique.

Testing & Validation

1. Testing Approach

Testing was conducted continuously during development. Each feature was tested individually as it was implemented. API endpoints were verified using Postman to ensure correct request/response behavior.

The application was tested on real devices and browsers to ensure proper functionality and responsiveness.

2. Unit Testing

The following components were tested individually:

  • Fetching questions from the API
  • Submitting answers
  • Skipping questions
  • Session resume functionality

4. Usability Evaluation (Nielsen’s Heuristics)

Heuristic Issue Identified Improvement
Visibility of system status No loading indicator when fetching questions Add loader/spinner
Match with real world Some labels are technical Use simpler language
User control & freedom Limited undo options Add back/confirm actions
Consistency Different button styles across pages Standardize UI components
Error prevention Users can submit duplicate wrong answers Add confirmation (partially implemented)
Recognition over recall Some actions require memory Add hints/tooltips
Flexibility & efficiency No shortcuts for experienced users Add quick actions
Aesthetic design Some screens feel cluttered Improve spacing/layout
Error recovery Error messages not always clear Improve error descriptions
Help & documentation No help section Add more description on page
